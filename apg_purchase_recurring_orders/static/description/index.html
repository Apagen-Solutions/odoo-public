Purchase Recurring Orders

Automate Purchase Orders with Recurring Agreements

This module allows you to create and manage Recurring Purchase Order Agreements in Odoo. It enables businesses to automate the generation of purchase orders for repeated procurement needs, saving time and ensuring that no agreement is missed.

Key Features:

  • Create Recurring Agreements: Easily create new agreements and add products to the Agreement Order Line.
  • Generate Initial Order: Create the first purchase order directly from the agreement.
  • Smart Button for All Orders: View all purchase orders generated from the agreement in one place.
  • One-click Next Year Orders: Quickly generate next year's orders without manual entry.
  • Order Count Tracking: Automatically updates the number of generated orders.
  • Renewable Agreements: If prolongation type is set to Renewable, renew with a single click.
  • Scheduled Actions: Automatically generate recurring orders for the next year.
