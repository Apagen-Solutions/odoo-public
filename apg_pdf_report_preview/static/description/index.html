PDF Report Preview

Preview PDF Reports in Browser Before Downloading

Purpose:

This module enhances the Odoo reporting system by allowing users to preview PDF reports directly in their browser, avoiding the default behavior of automatically downloading them. It helps streamline the document review process.

Key Features:

  • View PDF reports in the browser instead of downloading.
  • Supports all standard Odoo PDF reports.
  • Faster access to reports without cluttering local storage.
  • No impact on original report generation process or formatting.
  • Improves productivity for users needing quick report validation.

Usage:

Once the module is installed, any PDF report generated from Odoo will open in a new browser tab or window. Users can review the content and then choose to download, print, or share the report as needed.
