Manual Currency Exchange Rate

Apply Custom Exchange Rates in Sales, Purchases, and Invoices

This module provides the flexibility to manually apply custom currency exchange rates in Sale Orders, Purchase Orders, and Invoices. It is especially useful when you want to override the system's default currency rate for specific transactions.

Key Features:

  • Manually set the exchange rate in:
    • Sale Orders
    • Purchase Orders
    • Customer and Vendor Invoices
  • Overrides the default currency rate set in Odoo
  • Accurate and flexible currency conversion handling
  • Useful for businesses working with varying or negotiated exchange rates

Usage:

When creating a Sale Order, Purchase Order, or Invoice, a field will be available to manually enter the exchange rate. The system will use this rate for currency conversion in that transaction instead of the default system rate.

Technical Details:

  • Compatible with Odoo 18
  • Seamless integration with Sales, Purchase, and Accounting modules
  • Does not affect other parts of the currency configuration
