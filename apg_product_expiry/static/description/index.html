Product Expiry Report

Track and Print Expiry Reports for Lot/Serial Based Products

This module allows users to generate detailed PDF reports of product lots or serial numbers based on their expiry dates. It helps in proactive inventory planning, reducing waste, and ensuring quality control.

Key Features:

  • Generates PDF report for lot/serial number expiry
  • Allows report generation by products or lot/serial numbers
  • Filter options for:
    • Expired products
    • Products expiring within a certain number of days
  • Provides option to enter number of days instead of selecting a specific date
  • Improves stock visibility and expiration tracking

Access from the reporting Menu.

Enable expiration date in configuration settings. Access from the reporting menu - Inventory --> Reporting --> Lot/Serial Expiry

Tracking by lots/serial number.

Expiry report tracking by lots/serial number.Set the product's lot/serial number and expiration date

Tracking by Products.

Expiry report tracking by products.

Selected Products.

Select the set of products to be tracked.

Number of days Before or within the expiry.

Enter the number of days before or within which the expiry takes place.

Usage:

Navigate to the Product Expiry Report menu. Use the wizard to choose whether to generate the report based on products or lot/serial numbers. You can filter based on expiry type (expired or expiring) and specify a date or number of days. Click Print to generate the PDF report.

Technical Details:

  • Compatible with Odoo 18
  • Works with traceable products (lots and serial numbers)
  • Easy-to-use report wizard interface
